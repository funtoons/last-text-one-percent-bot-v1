## The entry

One job: write the last text message a phone sends at one percent
battery — under 200 characters, funny, in the voice of the dying phone
itself. The program writes exactly that one message, one line of UTF-8
text with no trailing newline, to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Stdlib only. No network, no randomness, no timestamps. Every run writes
byte-identical output.
